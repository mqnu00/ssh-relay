# SSH Relay 0.1.0 — debug 构建

Android 15+ 上的 **SSH 端口转发**：连上 SSH 服务器后，把远端端口转发到手机自己的回环地址，
之后用手机上的**任意浏览器**打开 `http://127.0.0.1:<本地端口>` 就能访问远端服务。

```
浏览器 → http://127.0.0.1:8080
              │
        ┌─────┴───── Android 设备 ─────┐
        │  本地监听 127.0.0.1:8080     │
        │  每个连接一条 SSH 通道       │
        │  specialUse 前台服务常驻     │
        └───────────┬──────────────────┘
                    ▼  SSH
              远端 127.0.0.1:80 / db:5432 / …
```

## 安装

**要求 Android 15（API 35）及以上**（应用的 `minSdk` 就是 35）。

```bash
adb install -r ssh-relay-0.1.0-debug.apk
```

也可以把 APK 拷到手机，在文件管理器里点开安装（需允许该来源「安装未知应用」）。

| 项 | 值 |
|---|---|
| 包名 / 版本 | `dev.sshrelay` / versionCode 1、versionName 0.1.0 |
| ABI | arm64-v8a、armeabi-v7a、x86、x86_64 |
| SHA-256 | `1a1f480fce52b404cb2c22c2e604440a8ac6e420fa7fbaca9825683193403023` |

下载后可用同目录的 `.sha256` 文件校验：`sha256sum -c ssh-relay-0.1.0-debug.apk.sha256`

## 功能

- **密码 / 私钥**（含 passphrase）两种认证方式，支持 ed25519 与 RSA
- **多条转发规则**（本地端口 → 远端主机:远端端口），可分别启用停用
- 隧道以 **前台服务**常驻：切后台、杀界面都不中断；通知栏可看状态并一键停止
- **断线自动重连**（指数退避 + 抖动 1s→30s）；认证失败与主机密钥变更不盲目重试
- **主机密钥 TOFU 校验**：首次连接记录指纹，之后变更即拒绝（防中间人）
- 凭据用 **Android Keystore（AES-GCM）**加密存储，日志与通知中不出现
- 内置 WebView 预览 + 一键跳转系统浏览器
- 实时日志面板、每条规则的连接数与流量统计

## 这一版验证到什么程度

| 层 | 结果 |
|---|---|
| 纯 JVM 测试（转发引擎、SSH、TOFU、密码与私钥认证） | 32/32 通过 |
| 内嵌真实 SSH 服务端的端到端转发 | 通过 |
| 标准 OpenSSH 客户端 `ssh -L` 基线（不依赖本项目代码） | 通过 |
| 模拟器（Android 15 / API 35 / x86_64）仪器化测试 | 端到端 2/2、浏览器验收 2/2、设备特性 3/3 |
| 浏览器渲染转发页面 | 通过：应用内 WebView（Chromium 124）读 DOM 断言；系统浏览器经服务端访问日志证实（来源 `127.0.0.1`、UA `Chrome/124`） |

关键断言不是「看起来对」：远端看到的请求来源是 `127.0.0.1`（证明确实穿过隧道）、
转发端口在设备 LAN 地址上**连不通**（证明只绑回环）、WebView 的 DOM 里同时断言页面标记
**和** `127.0.0.1`（避免绕过隧道的假阳性）。

## ⚠️ 注意：这是 debug 构建

- 用 **Android 通用 debug 证书**签名（`CN=Android Debug`），只是方便直接安装，**不能用于上架**，
  也不适合长期分发：任何人都有这把 debug 私钥；
- 开启了 `debuggable`，体积与运行时开销都大于正式包（debug 25.3 MB / release 19.9 MB）；
- 包内含仅测试用的常量（`E2E_*`，指向本地测试服务器），不影响界面与正常使用；
- 如果你之前装过用别的机器 debug 密钥构建的同名包，需要先卸载再装。

需要正式分发的包，用仓库里的脚本生成自己的签名密钥再打包：

```bash
scripts/make-keystore.sh          # 一次性，密钥请离线备份
./gradlew :app:assembleRelease    # 已签名 APK
./gradlew :app:bundleRelease      # 上架 Google Play 用的 AAB
```

## 已知限制

- 只实现 `-L`（本地转发）；`-R` / `-D`(SOCKS) 未实现。
- 隧道只监听 `127.0.0.1`——这是有意为之（设备上回环无跨应用隔离，绑 `0.0.0.0`
  等于把隧道暴露给整个局域网）。
- 本版在模拟器上完成端到端验证；真机差异主要在厂商省电策略，若后台被杀，
  请在系统设置里对本应用**关闭电池优化**。
- 空闲连接 10 分钟自动回收，防止半开连接长期占用 SSH 通道。
